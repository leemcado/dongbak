# assets

삽화와 선지 사진을 두는 곳. 현재는 자리만 잡혀 있고 렌더러가 실제 파일을 읽지 않는다
(`illust` 박스는 '삽화' 글자만, `선지사진` 은 선지 텍스트만 그린다).

- 삽화는 가급적 **SVG** 로. 래스터보다 가볍고, 격자 필터가 벡터 윤곽에 훨씬 잘 반응한다.
- 파일명은 문항과 묶어서: `illust-<범주>-<번호>.svg`, `choice-<범주>-<번호>-<선지>.png`
- 실제 로드를 붙이려면 `js/door.js` 의 `drawText()` 에서 `b.role==='illust'` /
  `b.role==='o'` 분기에 이미지 그리기를 더한다. 이때도 **필터 문법**을 지킬 것 —
  이미지를 그대로 칠하지 말고 거리장으로 바꿔 점 반지름에 기여시킨다.
