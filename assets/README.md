# assets

노션 export(`notion.zip`)에서 가져온 문항 이미지. 900px로 축소해 두었다.

```
club/     마스코트 4지선다용 로고 변형 4종 (정답은 mascot-red-cat)
history/  문항별 삽화·인물 사진·힌트 이미지
brain/    문제 상황 일러스트
```

`data/questions.json` 의 각 문항이 `img` 배열로 이 파일들을 가리킨다.

**아직 렌더러가 이 이미지를 읽지 않는다.** `js/door.js` 의 `drawText()` 는 텍스트만
그린다. 붙이려면 `b.role==='illust'` / `b.role==='o'` 분기에 이미지 그리기를 더하되,
**필터 문법**을 지킬 것 — 이미지를 그대로 칠하지 말고 거리장으로 바꿔 점 반지름에
기여시킨다. 특히 `선지사진` 유형(마스코트 문제)은 이미지가 없으면 선지 텍스트만
보이므로 사실상 문제가 성립하지 않는다.
