# 동아리 박람회 퀴즈

고려대 컴퓨터 동아리 KUCC 박람회 부스용 퀴즈. 7문제를 다 맞히면 래번클로 기숙사 문이 열리는 연출로 끝남.

## 실행

```
bash serve.sh
```

포트를 바꾸려면 뒤에 숫자. 서버가 뜨면 메인 창은 전체화면으로, 관리자 창은 일반 창으로 같이 열림. 종료는 Ctrl+C.

`file://` 로 열면 빈 화면. 모듈과 문제 데이터가 CORS 에 막히므로 반드시 `http://localhost` 경유.

메인 창은 늘 보이는 상태로 둘 것. 다른 창에 가리면 브라우저가 렌더링을 멈춰 애니메이션이 얼어붙음. 메인은 한 번에 하나만. 두 개 이상이면 관리자 화면이 엉뚱한 문항을 띄우고 경고줄이 뜸.

## 단축키

메인 창과 관리자 창 어느 쪽에서 눌러도 동작. 한글 입력 상태에서도 먹힘.

- `스페이스` 정답
- `Esc` 오답
- `Backspace` 직전 판정 하나 취소. 문이 열리기 시작한 뒤에는 잠김
- `R` 처음부터
- `E` 한글/영어 전환
- `1`~`6`, 마우스 클릭 선지 고르기. 메인 창에서만

부스에서는 TF 가 문제를 읽어주고 참가자의 구두 답변을 듣고 스페이스나 Esc 로 채점. 관리자 화면에 문제 전문·선지·정답·해설·다음 문제가 전부 나옴.

## 문제 고치기

`data/questions.json` 하나만 손보면 됨. 한 문항이 한 줄. 삽화와 선지 사진은 `assets/` 아래에 두고 `img` 로 가리킴.

`t` 는 문항 유형(주관식·4지선다·6지선다·주관식삽화·4지선다삽화·선지사진), `c` 는 범주(club·history·brain), `l` 은 난이도(쉬움·보통·어려움), `a` 는 정답. 선다형이면 인덱스, 주관식이면 허용 답안 배열. `qe`/`oe`/`ae` 가 영어판. `x` 는 해설이라 관리자 화면에만 나옴.

출제는 club 쉬움 → club 보통 → club 어려움 → history 쉬움 → history 보통 → history 어려움 → brain 어려움 순으로 각 칸에서 하나씩 뽑음. 칸 하나가 비면 그 자리가 깨지므로 문항을 지울 때 주의.
